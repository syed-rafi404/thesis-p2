# Python Variables and Data Types

In this lecture, we will cover the basics of Python variables and data types. We will understand how variables work and explore different data types in Python.

## Key Takeaways
- Variables are used to store data in Python.
- Python is dynamically typed, meaning you don't need to specify the data type when declaring a variable.
- Common data types in Python include `int`, `float`, `str`, and `bool`.
- Variable naming conventions in Python follow specific rules.

## Python Variables
- **Core Idea**: Variables are containers that hold data. They allow us to store and manipulate information in our programs.

### Example
```python
num = 10
```
- **Explanation**: Here, `num` is a variable that holds the integer value `10`.


- **Watch out:** Python is dynamically typed, so you can change the type of a variable later in your program without redeclaring it.

## Data Types
- **Core Idea**: Different types of data require different operations and storage methods.

### String
- **Definition**: A string is a sequence of characters.
- **Example**
    ```python
    Fruit = 'Apple'
    ```
- **Explanation**: `Fruit` is a variable that stores the string `'Apple'`.


### Integer
- **Definition**: An integer is a whole number, positive or negative, without decimals.
- **Example**
    ```python
    Age = 10
    ```
- **Explanation**: `Age` is a variable that stores the integer `10`.


### Float
- **Definition**: A float is a number with a decimal point.
- **Example**
    ```python
    Float = 3.5
    ```
- **Explanation**: `Float` is a variable that stores the float `3.5`.


### Boolean
- **Definition**: A boolean is a data type that has one of two possible values: `True` or `False`.
- **Example**
    ```python
    isV = True
    ```
- **Explanation**: `isV` is a variable that stores the boolean value `True`.


## Variable Naming Conventions
- **Core Idea**: Proper naming conventions make your code more readable and maintainable.

### Rules
1. **Use lowercase letters**: Start variable names with a lowercase letter.
2. **No spaces**: Do not use spaces in variable names.
3. **Underscores instead of spaces**: Use underscores to separate words in variable names.
4. **Case sensitivity**: Python is case-sensitive, so `my_name` and `My_Name` are considered different variables.

### Examples
```python
Iname = "Rafi"
name1 = "Rafi"
my_name = "Rafi"
```
- **Explanation**: `Iname` and `name1` are correctly named, while `myNam` is incorrectly named because it doesn't follow the naming convention.
