# Python Variables and Data Types

This lecture covers the basics of Python variables and data types, focusing on how to define and use variables effectively.

## Key Takeaways
- Variables are containers for storing data values.
- Python supports various data types including strings, integers, floats, and booleans.
- Variable names must follow specific naming conventions.
- Python is case-sensitive.

## Python Variables
### What is a Variable?
A variable is like a box where you can store different types of data. For example, you can store a book, an apple, or a number in a box.

**Example:**
```python
fruit = 'Apple'
```


### Integer
An integer is a whole number without a decimal point. In Python, you can assign an integer value to a variable.

**Example:**
```python
age = 10
```


### String
A string is a sequence of characters enclosed in single or double quotes. You can store text in a string variable.

**Example:**
```python
fruit = 'Apple'
```


### Float
A float is a number with a decimal point. You can assign a float value to a variable.

**Example:**
```python
pi = 3.1416
```


### Boolean
A boolean can have two values: `True` or `False`.

**Example:**
```python
isV = True
```

### Naming Conventions
- Use lowercase letters for variable names.
- Avoid spaces; use underscores instead.
- Be consistent with naming conventions.

**Examples:**
```python
i_name = "Rafi"
name1 = "Rafi"
my_name = "Rafi"
```


### Case Sensitivity
Python is case-sensitive. Therefore, `age` and `AGE` are considered different variables.

**Example:**
```python
age = 10
AGE = 10
```
