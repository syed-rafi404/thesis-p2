# Python Variables and Data Types

This lecture covers the basics of Python variables and data types, focusing on how to define and use variables effectively.

## Key Takeaways
- Variables are containers for storing data values.
- Python supports various data types including strings, integers, booleans, and floats.
- Variable names must follow specific naming conventions.
- Python is case-sensitive.

## Introduction to Variables
Variables are like boxes where you can store different types of data. For example, you can store a book, an apple, or a number in a box.

### Example
```python
myBox = "Apple"
```

**Watch out:** Variable names must start with a letter or an underscore.

## Data Types in Python
Python supports several data types:

### String
A string is a sequence of characters. You can define a string using either single or double quotes.

### Example
```python
fruit = 'Apple'
```

### Integer
An integer is a whole number, positive or negative, without decimals.

### Example
```python
age = 10
```

### Float
A float is a number with a decimal point.

### Example
```python
pi = 3.1416
```

### Boolean
A boolean represents one of two values: `True` or `False`.

### Example
```python
isStudent = True
```

## Naming Conventions
Variable names must follow specific rules:

### Rule 1: Start with a letter or an underscore
```python
name = "Sakib"
```

### Rule 2: Avoid spaces, use underscores instead
```python
my_name = "Rafi"
```

### Rule 3: Be consistent with case sensitivity
```python
age = 10
Age = 20  # Different from age
```

## Answers

2. A string is defined using single or double quotes, e.g., `fruit = 'Apple'`.
3. An integer is a whole number without decimals, while a float has a decimal point.
