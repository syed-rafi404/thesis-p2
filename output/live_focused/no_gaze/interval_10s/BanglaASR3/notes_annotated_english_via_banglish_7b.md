# Conditional Statements
We use conditional statements in computers to make logical decisions.

## Key takeaways
- We use `if`, `elif`, `else` to create conditional statements.
- We can store user input in a variable.
- In the `if` block, if the condition is true, it will print a specific message.
- In the `elif` block, if the previous condition is false but the next condition is true, it will print a specific message.
- In the `else` block, if all conditions are false, it will print a default message.

## Check yourself
1. Write a Python code to check if the weather is "Rain" and print "Bring Umbrella".
2. Write a Python code to check if the weather is "Sunny" and print "Wear White Coat".
3. Write a Python code to check if the weather is neither "Rain" nor "Sunny" and print "Just Come".
4. What will be printed if the weather is "Cloudy"?
5. How do you store user input in a variable?

### Answers
1. ```python
   if weather == "Rain":
       print("Bring Umbrella")
   ```
2. ```python
   elif weather == "Sunny":
       print("Wear White Coat")
   ```
3. ```python
   else:
       print("Just Come")
   ```
4. "Just Come"
5. Using the `input()` function to get user input and storing it in a variable like `weather = input("Enter the weather: ")`.
