# Conditional Statements
Conditional statements help the computer make decisions based on user input.

## Key takeaways
- Conditional statements are fundamental for making decisions in programming.
- The `if` keyword starts a conditional block.
- The `elif` keyword checks another condition if the first one is false.
- The `else` keyword provides a default action if none of the conditions are met.
